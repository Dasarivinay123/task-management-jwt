# Task Management Frontend (React)

## 📌 Overview

This is the frontend of the Task Management System built using React. It allows users to register, login, and manage their tasks (add, update, delete) through a simple and responsive UI.

## 🚀 Features

* User Registration & Login
* JWT-based Authentication
* Create, Update, Delete Tasks
* Real-time Search & Filtering of Tasks (Client-side filtering using React state)
* Protected Routes
* Responsive UI using Bootstrap

## 🛠 Tech Stack

* React
* React Router
* Axios
* Bootstrap

## ⚙️ Setup & Run

```bash
npm install
npm start
```

## 🔗 Backend

Make sure backend is running before starting frontend.
